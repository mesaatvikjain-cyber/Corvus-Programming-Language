# Corvus v4.4 Hands-On Tutorial: Modern Syntax Ergonomics & Smart Type Inference

Welcome to **Corvus Version 4.4**! 

Based on community developer feedback regarding bracket muscle memory and declaration fatigue, Corvus v4.4 introduces **Universal Dual Syntax** and **Smart Type Inference**, while maintaining **100% backwards compatibility** with all legacy Corvus code across both the Interpreter and the Native C99 Compiler.

---

## 🌟 What's New in v4.4?

1. **Universal Dual Bracket Support**:
   - **Code Blocks**: You can now use standard `{ ... }` (familiar to C, Java, JavaScript, Rust, Go developers) OR classic `[ ... ]` (Corvus signature blocks).
   - **Lists & Arrays**: You can now use standard `[ ... ]` OR classic `{ ... }`.
2. **Smart Type Inference**:
   - Declare variables cleanly with `set name = value`. Corvus infers the type automatically!
   - No boilerplate `set <type>; name = value` required for standard scripting.
3. **Semicolon-Optional Typed Declarations**:
   - Write `set int count = 42` without requiring a semicolon between type and variable name.
4. **Top-Level `const` Declarations**:
   - Declare constants directly with `const PI = 3.14159` or `const MAX_CONNECTIONS = 100`.
5. **Flexible Parentheses in Control Flow**:
   - Write `if x > 10 { ... }` or `if (x > 10) [ ... ]`.
6. **Full Parity Across Interpreter & Compiler**:
   - All v4.4 features compile to optimized native C99 (`-O3`) executables with `CorvusC_c.py` or run directly via `Corvus.py`.

## 1. Universal Dual Bracket Scoping

Mainstream programmers have deeply ingrained muscle memory for curly braces `{ ... }` for code blocks and square brackets `[ ... ]` for arrays. Corvus v4.4 welcomes both!

```corvus
// Modern C/Rust style:
mk greet(name) {
    if name == "Saatvik" {
        log("Welcome creator!")
    } else {
        log(f"Hello, {name}!")
    }
}

// Classic Corvus style (still 100% supported):
mk legacy_greet(name) [
    if (name == "Saatvik") [
        log("Welcome creator!")
    ] else [
        log(f"Hello, {name}!")
    ]
]
```

---

## 2. Universal Dual Syntax for Lists and Arrays

You can instantiate lists using standard square brackets `[1, 2, 3]` or classic Corvus curly braces `{1, 2, 3}`:

```corvus
// Standard bracket list:
set items = [10, 20, 30, 40]
log(items[0]) // 10

// Classic list:
set numbers = {100, 200, 300}
log(numbers[1]) // 200

// Dictionaries remain intuitive with key: value pairs:
set user = {"username": "corvus_dev", "role": "admin"}
log(user["username"])
```

## 3. Smart Type Inference

Eliminate declaration fatigue! Corvus infers types at declaration:

```corvus
// v4.4 Inferred Declarations:
set language = "Corvus"     // inferred as string
set version = 4.4           // inferred as float
set active = true           // inferred as boolean
set primes = [2, 3, 5, 7]   // inferred as list

log(language, version, active, primes)
```

If you want strict static typing or explicit annotations, you can still specify types with or without semicolons:

```corvus
// Semicolon-optional typed declarations:
set int max_score = 100
set flo pi_approx = 3.14159

// Classic syntax:
set int; legacy_score = 100
```

---

## 4. First-Class `const` Declarations

Define immutable constants cleanly at any scope:

```corvus
const APP_NAME = "Corvus Engine"
const MAX_BUFFER = 4096
const GOLDEN_RATIO = 1.618

log(APP_NAME, MAX_BUFFER, GOLDEN_RATIO)
```

---

## 5. Modern Pattern Matching with Braces

Pattern matching now supports clean modern curly brace blocks:

```corvus
set http_status = 200

match http_status {
    case 200 => {
        log("OK: Request succeeded")
    }
    case 404 => {
        log("Not Found: Resource does not exist")
    }
    else => {
        log("Server error or unknown status")
    }
}
```
