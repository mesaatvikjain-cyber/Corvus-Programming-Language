Welcome to **Corvus Version 5.2**!

RavenLM features causal autoregressive decoding, multi-head self-attention, dual-engine inference (PyTorch + zero-dependency NumPy fallback), and interactive CLI model commands (`corvus ai model`, `complete`, `gen`, `train`).

## 🧠 1. Architecture of RavenLM

RavenLM is built from the ground up to understand Corvus grammar, unique bracket delimiters (`[ ... ]`, `{ ... }`), native matrix operators (`@`), and standard library idioms.

### Model Specifications
* **Architecture**: Causal Autoregressive Decoder Transformer (NanoGPT-style).
* **Weights & Parameters**: 166,464 learned parameters.
* **Transformer Configuration**:
  - **3 Decoder Layers** with residual skip connections.
  - **4 Multi-Head Attention Heads** ($d_{\text{model}} = 64$, head dimension $= 16$).
  - **GELU Non-Linearity** in 4x expansion Feed-Forward Networks.
  - **Layer Normalization** (pre-norm / post-norm architecture).
  - **Learned Positional Embeddings** with a 64-token causal context window.
* **Trained Cross-Entropy Loss**: Converged to **0.8796** across 20 epochs on Corvus codebase scripts.

## ⚡ 3. Autoregressive Code Completion (`corvus ai complete`)

Prompt the neural model with an incomplete Corvus code snippet, and RavenLM will autoregressively predict subsequent tokens through its attention layers:

```bash
corvus ai complete "mk func fibonacci(n) ["
```

The model applies causal self-attention over the prefix, filters logits via top-$k$ sampling with temperature scaling ($T = 0.7$), and synthesizes the function body and closing brackets `[ ... ]`.

## 🏋️ 5. Training & Fine-Tuning RavenLM (`corvus ai train`)

Developers can retrain or fine-tune RavenLM on their own custom Corvus codebases:

```bash
# Fine-tune the model for 30 epochs
corvus ai train 30
```

### The Training Pipeline (`Interpreter/train_raven.py`)
1. **Corpus Harvesting**: Scans all `.crv` files in `Examples-and-Tests/` and `StdLib/`.
2. **Tokenizer**: Builds a vocabulary over printable ASCII characters and Corvus syntax symbols (`raven_vocab.json`).
3. **Causal Sequences**: Creates shifted token pairs $(X, Y)$ where $Y_t = X_{t+1}$.
4. **Optimization**: Trains with AdamW, gradient clipping ($1.0$), and Cosine Annealing learning rate schedule.
5. **Dual Export**:
   - `raven_weights.pt`: PyTorch model checkpoint.
   - `raven_weights.json`: Portable weights for pure NumPy execution on machines without PyTorch.

## 🌐 6. Zero-Dependency Dual Execution Engine

To preserve Corvus's hallmark **100% zero-dependency standalone portability**:
- When **PyTorch** is available, RavenLM leverages PyTorch tensor acceleration.
- When PyTorch is **not installed** (e.g. inside `corvus.exe` standalone binaries), RavenLM transparently activates the **NumPyRavenLM** inference engine, executing matrix projections and softmax calculations with zero external pip packages.
