## 2. AI Matrix Multiplication (`@` Operator)

Corvus v4.3 adds the first-class `@` operator for vector and matrix mathematics, matching NumPy/PyTorch idioms directly in syntax.

```corvus
# 1. Native 2D List Matrix Multiplication
set lis; A = [[1, 2], [3, 4]]
set lis; B = [[5, 6], [7, 8]]
set any; C = A @ B
log("Native List MatMul:", C)  # [[19, 22], [43, 50]]

# 2. NumPy Array MatMul
get numpy;
set any; na = numpy.array([[2, 0], [1, 3]])
set any; nb = numpy.array([[1, 2], [3, 4]])
set any; nc = na @ nb
log("NumPy MatMul:", nc)

# 3. PyTorch Tensor MatMul
get torch;
set any; ta = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
set any; tb = torch.tensor([[2.0, 0.0], [1.0, 2.0]])
set any; tc = ta @ tb
log("PyTorch MatMul:", tc)
```

## 3. Developer Tooling & Ecosystem (`fmt`, `test`, `cpm`, `--strict`)

Corvus v4.3 unifies developer tooling into the core CLI:

- **Canonical Code Auto-Formatter (`corvus fmt`)**:
  ```bash
  python Interpreter/Corvus.py fmt myfile.crv
  python Interpreter/Corvus.py fmt myfile.crv --check
  ```
- **Auto-Discovery Test Runner (`corvus test`)**:
  Discovers all test suites (*test*.crv / *suite*.crv) and runs them in sequence with a summary report:
  ```bash
  python Interpreter/Corvus.py test
  ```
- **Strict Static Type Checker (`corvus --strict`)**:
  Pre-execution static analysis detecting type mismatches, variable scope issues, and function arity errors:
  ```bash
  python Interpreter/Corvus.py --strict myfile.crv
  ```
- **Corvus Package Manager Integration (`cpm`)**:
  ```bash
  python Interpreter/Corvus.py init
  python Interpreter/Corvus.py install <package>
  python Interpreter/Corvus.py list
  python Interpreter/Corvus.py remove <package>
  ```

## 4. Rust-Style Error Diagnostics & Heuristics

Corvus delivers actionable terminal diagnostics:

- **Error Catalog (`--explain <CODE>`)**: Over 18 indexed codes (E0101–E0502) explaining root causes and verified code fixes.
  ```bash
  python Interpreter/Corvus.py --explain E0101
  ```
- **Did you mean? Levenshtein Matching**: Corrects typos in variable names and keywords (e.g. typing `false` suggests `fal`, `def` suggests `func`).
- **AI-Fix Assistant (`--ai-fix`)**: Provides instant error solutions and search links directly in the console.

## 6. AST Optimization Engine & Modern Syntax

### High-Performance AST Optimizer (`--optimize`)
Corvus analyzes AST representations before evaluation:
- **Constant Folding**: Evaluates constant arithmetic at compile/load time (e.g. `10 * 20 - 5` folds to `195`).
- **Algebraic Simplification**: Automatically simplifies identity operations (`x * 0 -> 0`, `x * 1 -> x`, `x + 0 -> x`, `x - 0 -> x`).
- **Dead Branch Pruning**: Eliminates unreached `if (fal)` blocks and collapses static `if (tru)` branches.
- **Ternary Simplification**: Folds compile-time conditional expressions.

```bash
python Interpreter/Corvus.py Examples-and-Tests/18_optimization_and_modern_syntax_suite.crv --optimize
```

### String Interpolation (F-Strings) & Ternaries
Write clean, readable modern Corvus code:
```corvus

# Modern F-Strings with expressions:
```
