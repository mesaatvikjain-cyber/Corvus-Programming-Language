# Corvus v1.1 Tutorial: Language Fundamentals & AST Interpreter

Welcome to the **Corvus Version 1.1 Tutorial**! In this guide, you will learn the core foundations of the Corvus language, including its unique syntax, variables, block scoping `[ ... ]`, list literals `{ ... }`, control flow, functions, OOP classes, and the CPM Package Manager.

---

## 1. Syntax Foundations: Square Brackets & Curly Braces

Corvus replaces traditional indentation (Python) or curly braces (C/JS) with **square brackets `[ ... ]` for code blocks**, while using **curly braces `{ ... }` for native lists**.

```corvus
# Mutable Variable
var score = 100
set score = score + 50

# Immutable Constant
const PROGRAM_NAME = "Corvus Core v1.1"

# Native List Literal
var scores = {95, 88, 100, 76}
```

## 2. Control Flow & Branching

```corvus
var temperature = 32

if (temperature > 30) [
    log("It's hot outside!")
] elsif (temperature == 20) [
    log("Perfect weather!")
] else [
    log("It's chilly!")
]

# Loops
var i = 0
while (i < 5) [
    log("Iteration: " + str(i))
    set i = i + 1
]
```

## 3. Functions & Lambdas

Functions are defined with `func` and return values using `givout`.

```corvus
func calculate_discount(price, discount_rate) [
    var final_price = price - (price * discount_rate)
    givout final_price
]

var total = calculate_discount(100, 0.20)
log("Total price: " + str(total))  # 80.0

# Lambda Expressions
var double_val = lambda (x) -> x * 2
log(double_val(21))  # 42
```

## 4. Object-Oriented Classes

```corvus
class BankAccount [
    func init(owner, balance) [
        set self.owner = owner
        set self.balance = balance
    ]

    func deposit(amount) [
        set self.balance = self.balance + amount
        log("Deposited: " + str(amount) + " | New Balance: " + str(self.balance))
    ]
]

var account = BankAccount("Saatvik", 500)
account.deposit(250)
```
