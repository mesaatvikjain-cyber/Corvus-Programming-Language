# Corvus v2.0 Tutorial: Multi-Platform Native Assembly Compiler

In **Version 2.0**, Corvus introduced a native 64-bit NASM assembly compiler backend (`CorvusC.py`) capable of outputting standalone native binary executables for **Windows (Win64 ABI)**, **Linux (ELF64 System V ABI)**, and **macOS (Mach-O System V ABI)**, alongside functional pipelines (`|>`) and pattern matching.

---

## 1. Functional Pipelines (`|>`) & Pattern Matching

```corvus
# Functional Pipeline Operator (|>)
func double(x) [ givout x * 2 ]
func add_ten(x) [ givout x + 10 ]

var result = 5 |> double |> add_ten
log(result)  # 20

# Pattern Matching (match / case)
var status = 200

match (status) [
    case 200: log("OK - Success")
    case 404: log("Not Found")
    case 500: log("Internal Error")
    else: log("Unknown Status")
]
```

---

## 2. Compiling Native Binary Executables

Corvus v2.0 translates AST into native NASM 64-bit assembly files (`.asm`), assembles them with NASM, and links them into standalone native executables!

### Compiling for Windows (Win64 `.exe`)
```bash
python Version_2.0/Compiler/CorvusC.py Version_2.0/Examples-and-Tests/09_pipeline_and_pattern_matching.crv --target windows -r
```

### Compiling for Linux (ELF64 `.elf`)
```bash
python Version_2.0/Compiler/CorvusC.py Version_2.0/Examples-and-Tests/09_pipeline_and_pattern_matching.crv --target linux -r
```

### Compiling for macOS (Mach-O 64)
```bash
python Version_2.0/Compiler/CorvusC.py Version_2.0/Examples-and-Tests/09_pipeline_and_pattern_matching.crv --target macos -r
```
