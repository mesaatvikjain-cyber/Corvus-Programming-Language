## ⚡ 1. Tiered JIT Execution Engine (`corvus --jit`)

Corvus v5.1 features a Just-In-Time (JIT) compilation tier built atop the stack bytecode VM (`CorvusVM`). Hotspots (functions and loops called repeatedly) are detected via execution counters and dynamically optimized on the fly.

### Running with JIT Acceleration
```bash
corvus --jit Examples-and-Tests/21_bytecode_vm_suite.crv
```

### Hotspot Detection
When a loop iteration or function invocation passes the hotness threshold (e.g. 100+ executions), the JIT compiler generates optimized bytecode routines and eliminates redundant stack lookups, delivering dramatic speedups for heavy numerical, matrix, and algorithmic code without requiring ahead-of-time C builds.

## 🗄️ 2. Real-Time Async WebSockets & Channels

Corvus v5.1 introduces Go/Rust-style channels and full real-time WebSocket communication in the standard library.

### Asynchronous Channels (`channel`)
Communicate safely between concurrent tasks (`crow.fly`) using bounded or unbounded thread-safe channels:
```corvus
get channel

set any; ch = channel.new(10)

crow.fly(mk func() [
    ch.send("Telemetry ping")
    ch.send("Worker heartbeat")
    ch.close()
])

set any; msg1 = ch.recv()
log("Channel received: " + msg1)
set any; msg2 = ch.recv()
log("Channel received: " + msg2)
```

### Real-Time WebSocket Server (`web.ws_server`)
Build bidirectional real-time microservices and event pipelines:
```corvus
get web

set any; ws = web.ws_server(8081)

ws.on_connect(mk func(client_id) [
    log("New client connected: " + client_id)
    ws.send(client_id, "Welcome to Corvus Real-Time Server!")
])

ws.on_message(mk func(client_id, msg) [
    log("Message from " + client_id + ": " + msg)
    ws.broadcast("Echo: " + msg)
])

log("WebSocket server listening on ws://127.0.0.1:8081...")
ws.listen()
```

## 🧠 4. RavenAI 3.0: Natural Language Code Gen & Auto-Refactor

Corvus v5.1 expands the intelligent AI developer toolkit with automated prompt-driven code generation and static refactoring.

### Generate Corvus Code from English (`corvus ai gen`)
Prompt RavenAI to synthesize idiomatic Corvus code for functions, classes, and algorithms:
```bash
corvus ai gen "Write a binary search function for a sorted list"
corvus ai gen "Create a high-score leaderboard class with sort and filter"
```

### Auto-Refactor Legacy Code (`corvus ai refactor`)
Modernize scripts, upgrade syntax to idiomatic patterns, and optimize performance:
```bash
corvus ai refactor my_legacy_script.crv
```
RavenAI inspects expressions, automatically refactors loops into vectorized matrix operations where appropriate, eliminates dead assignments, and updates deprecated syntax.

## 🎮 5. Corvus GameKit, 2D Physics & Retro Audio Synthesizer

Build interactive 2D arcade games and simulations with zero external graphics or audio libraries!

### 2D Physics & Game Loop (`gamekit`)
```corvus
get gamekit

# Create 2D vectors and colliders
set any; v1 = gamekit.vec2(10.0, 20.0)
set any; v2 = gamekit.vec2(5.0, 5.0)
set any; v3 = v1.add(v2)

set any; c1 = gamekit.circle(10.0, 10.0, 5.0)
set any; c2 = gamekit.circle(14.0, 10.0, 5.0)
log("Circles collide: " + str(c1.intersects(c2)))

# Particle system burst
set any; emitter = gamekit.emitter(0.0, 0.0, 50)
emitter.burst()
emitter.update(0.016)
```

### Retro Audio Synthesizer (`audio`)
Generate square waves, sine waves, frequency sweeps, and retro sound effects for arcade games:
```corvus
get audio

# Play a 440 Hz A4 tone for 0.25 seconds
audio.play_tone(440, 0.25)

# Play a classic arcade power-up chord
audio.play_chord([523, 659, 784], 0.3)
```

## 📊 6. Active-Record SQLite ORM & Reactive DataFrames

Handle database persistence and data science workflows out of the box with zero third-party dependencies.

### SQLite ORM (`orm`)
```corvus
get orm

set any; db = orm.open(":memory:")
set any; User = db.model("users", {"name": "TEXT", "score": "INTEGER"})

User.create({"name": "Alice", "score": 95})
User.create({"name": "Bob", "score": 82})
User.create({"name": "Charlie", "score": 99})

set any; top_players = User.where("score >= 90").order_by("score DESC").all()
log("Top players found: " + str(len(top_players)))
for p in top_players [
    log("Player: " + p["name"] + " | Score: " + str(p["score"]))
]
```

### Reactive DataFrames (`dataframe`)
Perform statistical data wrangling, column filtering, and aggregations:
```corvus
get dataframe

set any; df = dataframe.from_records([
    {"city": "Tokyo", "temp": 18.5, "humidity": 62},
    {"city": "London", "temp": 14.2, "humidity": 78},
    {"city": "New York", "temp": 22.0, "humidity": 55}
])

log("Shape: " + str(df.shape()))
log("Columns: " + str(df.columns()))

set any; stats = df.describe()
log("Temperature stats: " + str(stats["temp"]))
```
