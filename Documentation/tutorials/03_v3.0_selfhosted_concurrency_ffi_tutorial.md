# Corvus v3.0 Tutorial: Self-Hosted Compiler, Concurrency & Native C FFI

**Version 3.0** brought major architectural milestones: Three-Address Code (TAC) Intermediate Representation (IR), a Self-Hosted Compiler written in pure Corvus (`CorvusCompiler.crv`), the "Murder of Crows" 🐦 Multi-Threaded Concurrency Engine, Native C FFI, and Scope Memory Ref-Counting GC.

---

## 1. "Murder of Crows" 🐦 Multi-Threaded Concurrency Engine

Spawning concurrent tasks with `crow.fly`, synchronizing with `crow.flock`, and communicating over channels with `crow.channel`:

```corvus
func task_a() [
    log("Task A running on thread pool...")
    givout 42
]

func task_b() [
    log("Task B running concurrently...")
    givout 100
]

# Spawn concurrent worker tasks
var thread1 = crow.fly(task_a, {})
var thread2 = crow.fly(task_b, {})

# Synchronize task execution
var results = crow.flock({thread1, thread2})

# Thread-safe Channels
var channel = crow.channel()
channel.send("Hello from concurrent worker channel!")
var message = channel.receive()
log(message)
```

## 2. Native C Foreign Function Interface (FFI)

Dynamic binding and calling of native C shared libraries (`.dll`, `.so`, `.dylib`):

```corvus
# Load dynamic C library
var user32 = ffi.load("user32.dll")

# Bind native C symbol (MessageBoxA)
var MessageBox = ffi.bind(user32, "MessageBoxA", "int", {"int", "str", "str", "int"})

# Call native C function
ffi.call(MessageBox, {0, "Hello from Corvus C FFI!", "Corvus FFI", 0})
```

## 3. Scope Memory Ref-Counting GC (`mem` module)

```corvus
# Allocate 1024 bytes on the heap
var buffer = mem.alloc(1024)

# Inspect memory statistics
var stats = mem.stats()
log("Active Heap Allocations: " + str(stats.allocated))

# Free heap buffer
mem.free(buffer)
```
