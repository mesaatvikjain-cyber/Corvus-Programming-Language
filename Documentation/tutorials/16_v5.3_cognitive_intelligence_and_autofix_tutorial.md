## 1. Syntax-Aware Subword & BPE Tokenizer

Previous versions used character-level tokenization. In Version 5.3, Corvus features a custom Byte-Pair Encoding (BPE) subword tokenizer specifically built for Corvus keywords, control structures, and idiomatic idioms.

```corvus
get raven

set str; code = "mk func calculate(a, b) [ givout a @ b ]"
set any; tokens = raven.tokenize(code)

log("Original Character Count:", code.len())
log("Subword BPE Token Count :", tokens.len())
log("Roundtrip Decoded Code  :", raven.detokenize(tokens))
```

Key features:
- Core keyword subwords (`mk func `, `givout `, `crow.fly(`, `chan.new()`, `@`, `|>`) are encoded as atomic tokens.
- Lossless ASCII fallback for variable names and string literals.
- Compresses programs by **4.5x**, allowing 50+ lines of code to fit inside a 64-token context window!

## 2. Context-Free Grammar (CFG) Constrained Decoding

Large Language Models typically suffer from bracket hallucination (forgetting to close `]` or `}`). RavenAI 5.0 solves this natively using **Grammar-Constrained Decoding**.

During every step of autoregressive generation:
1. The parser state machine tracks the delimiter stack (`[`, `]`, `{`, `}`, `(`, `)`).
2. Any token that would produce an illegal grammar transition or unmatched closing bracket has its logit masked to $-\infty$.
3. Result: **100% syntactically valid Corvus code generation**.

```corvus
get raven

// Validate bracket depth and grammar balance
set any; state = raven.check_grammar("mk func loop(n) [ set i = 0; while (i < n) [ set i = i + 1; ] givout i; ]")
log("Is balanced:", state["balanced"]) // true
```

## 3. Autonomous Compiler Self-Healing (`--ai-fix`)

Have you ever accidentally written Python syntax or forgotten a bracket in your Corvus script?
Version 5.3 introduces the **Autonomous Self-Healing Compiler**.

### Running from CLI
Run any Corvus script with `--ai-fix`:

```bash
corvus my_script.crv --ai-fix
```

When an error occurs, Corvus:
1. Catches the syntax or runtime diagnostic.
2. Invokes RavenAI 5.0 to synthesize a minimally invasive patch.
3. Automatically rewrites the source file with the healed code.
4. Seamlessly re-executes the fixed program with zero downtime!

### Interactive Fix & Diagnostics
You can also inspect and dry-run fixes using:

```bash
# Preview suggested patch
corvus ai fix my_script.crv

# Apply patch directly to file
corvus ai fix my_script.crv --apply
```

## 4. RavenLM 5.0 Runtime API

Corvus programs can query model specifications and generate completions in real time:

```corvus
get raven

// Inspect neural model
set any; info = raven.model_info()
log("Model Name       :", info["name"])
log("Parameters       :", info["parameters"])
log("Decoding Engine  :", info["grammar_constraint"])

// Autoregressively complete code under CFG constraints
set any; completion = raven.complete("mk func fib(n) [", 20, 0.7)
log("Synthesized Function:
", completion)

// Next-token syntax prediction
set any; next_tok = raven.predict("mk func run() [ givout")
log("Predicted Next Token:", next_tok)
```
