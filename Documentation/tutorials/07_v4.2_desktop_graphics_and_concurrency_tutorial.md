# Corvus v4.2 Tutorial: Desktop 2D Graphics & Expanded Murder of Crows Concurrency

**Version 4.2** introduces desktop graphical application development and high-throughput parallel execution into Corvus with zero external pip dependencies.

---

## 1. Zero-Config Desktop 2D Graphics (graphics.crv)

Corvus v4.2 includes a native desktop canvas engine powered by std_graphics.py. You can create game windows, draw shapes and text, listen to real-time keyboard/mouse inputs, and control animation loops at fixed frame rates (graphics.fps(60)).

### Window Lifecycle & Drawing API:
`corvus
get graphics

# 1. Initialize Window (title, width, height, background_hex)
graphics.init_window(Corvus Canvas, 800, 600, #0f172a)

# 2. Main Game Loop
set int; x = 100
while (graphics.is_open()) [
    graphics.clear(#0b0f19)

    # Keyboard input handling
    if (graphics.is_key_pressed(Right)) [
        set x = x + 5
    ]
    if (graphics.is_key_pressed(Left)) [
        set x = x - 5
    ]

    # Draw shapes: rect, circle, line, text
    graphics.draw_rect(x, 200, 60, 60, #38bdf8, 1)
    graphics.draw_circle(400, 300, 40, #4ade80, 1)
    graphics.draw_text(Press Left/Right to Move Box, 20, 20, 18, #ffffff)

    # Maintain 60 Frames Per Second
    graphics.fps(60)
]
`

## 2. Expanded Murder of Crows Concurrency (crow)

Building upon v3.0's multi-threaded worker engine, v4.2 adds advanced concurrent patterns:

`corvus
# 1. Parallel Mapping across CPU cores
mk func square(n) [
    givout n * n
]

set lis; numbers = [1, 2, 3, 4, 5, 6, 7, 8]
set lis; squared = crow.parallel_map(square, numbers)
log(Parallel Squared:, squared)

# 2. Race Conditions (first task to finish wins)
mk func fetch_primary() [
    givout primary
]
mk func fetch_mirror() [
    givout mirror
]

set any; fastest = crow.race([fetch_primary, fetch_mirror])
log(Winner was:, fastest)

# 3. Dedicated Worker Nests (Actor Pattern)
set any; nest = crow.nest(4)   # Pool of 4 persistent workers
nest.submit(task1)
nest.submit(task2)
nest.shutdown()
`
