# Corvus v4.0 Tutorial: Native Standard Library, Interactive REPL & VS Code Extension v0.3.0

**Version 4.0** expanded Corvus into a full-featured developer ecosystem with a native standard library (`math.crv`, `string.crv`, `file.crv`, `sys.crv`), an interactive REPL shell with tab auto-completion, and VS Code extension v0.3.0.

---

## 1. Native Standard Library Modules

```corvus
# Native Math Module (math.crv)
var abs_val = math.abs(-42)
var max_val = math.max(10, 50)
var fact = math.factorial(5)  # 120
var sq = math.sqrt_approx(144) # 12

# Native String Utilities (string.crv)
var padded = string.pad_left("Corvus", 10, " ")
var empty_check = string.is_empty("")

# File I/O Module (file.crv)
file.write_all("output.txt", "Hello from Corvus v4.0 StdLib!")
var content = file.read_all("output.txt")

# System Module (sys.crv)
log(sys.get_platform())  # Outputs: Corvus Core 4.0 Native Runtime
```

---

## 2. Interactive REPL Shell Engine

Launch the interactive REPL shell:
```bash
python Version_4.0/Interpreter/Corvus.py --repl
```

REPL Directives:
```text
corvus> .help    # Displays available directives
corvus> .vars    # Inspect active variable environment
corvus> .funcs   # Inspect defined functions
corvus> .clear   # Clear screen
corvus> .reset   # Reset environment
corvus> .exit    # Exit REPL session
```

## 3. VS Code Extension v0.3.0

The VS Code extension provides:
- Real-time syntax checking & linter underline on document save.
- Commands: `Corvus: Run Current File`, `Corvus: Compile & Run Native Binary`, `Corvus: Open Interactive REPL Shell`.
- Integrated status bar button (`▶ Run Corvus`).
