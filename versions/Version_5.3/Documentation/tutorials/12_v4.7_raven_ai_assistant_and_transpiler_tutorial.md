# Corvus v4.7 Hands-On Tutorial: RavenAI Assistant, Code Explainer, Auto-Fixer & Python Transpiler

Welcome to **Corvus Version 4.7**!

Corvus v4.7 introduces **RavenAI** — a built-in, 100% offline intelligent developer assistant designed directly into the Corvus toolchain. Operating with zero third-party dependencies and zero external API calls, RavenAI brings intelligent code assistance, typo-tolerant documentation queries, structural AST analysis, error auto-fixing, and automated Python-to-Corvus transpilation straight to your command line.

---

## 🌟 Key Features of Version 4.7

1. **Typo-Tolerant Knowledge Assistant (`corvus ai ask`)**:
   - Matches queries using fuzzy sequence similarity algorithms (`difflib.SequenceMatcher`).
   - Understands misspelled terms like `"funtion"`, `"matix"`, or `"concurancy"` with high confidence and provides canonical, syntax-verified Corvus code examples.
2. **Structural Code Explainer (`corvus ai explain`)**:
   - Parses files or direct code snippets to analyze imported modules (`get`), classes (`cls`), functions (`mk func`), loops, conditional branching, and matrix operations (`@`).
   - Summarizes structural design and operational flow in human-readable terms.
3. **Automated Diagnostic Fixer (`corvus ai fix`)**:
   - Detects common Pythonisms (e.g., `print` -> `log`, `def` -> `mk func`, `return` -> `givout`) and unclosed brackets.
   - Integrates with the Corvus lexer and parser to pinpoint syntax errors and propose corrected code.
4. **Python-to-Corvus Transpiler (`corvus ai translate`)**:
   - Indentation-aware transpiler converting Python scripts into idiomatic Corvus code.
   - Handles variable declarations, control structures, function definitions, lists, dictionaries, and prints, outputting valid Corvus AST.
5. **Interactive Assistant REPL (`corvus ai chat`)**:
   - Interactive shell supporting conversational queries and prompt commands (`code--ask`, `code--summary`, `code--fix`, `code--translate`, `exit`).

## 🚀 CLI Commands & Examples

### 1. Typo-Tolerant Q&A (`corvus ai ask`)
Even with typographical errors, RavenAI finds the correct language reference:

```bash
corvus ai ask "how to define a funtion?"
```

**Output**:
```text
[RavenAI Knowledge Base]
Topic: Functions & Subroutines
Usage in Corvus:
Functions are declared using 'mk func name(params) [ ... ]' and return values with 'givout':

mk func add(a, b) [
    givout a + b
]

log(add(5, 10))
```

More examples:
```bash
corvus ai ask "how do matix operations work"
corvus ai ask "concurancy with crows"
corvus ai ask "how to make a class"
```

### 3. Automated Diagnostic Fixer (`corvus ai fix`)
RavenAI catches syntax mismatches, missing brackets, and accidental Pythonisms:

```bash
corvus ai fix "def calculate(x): print(x * 2)"
```

**Output**:
```text
[RavenAI Diagnostic & Fix Engine]
[!] Identified Issues:
  - Found Python 'def' syntax. In Corvus, define functions using 'mk func name(params) [ ... ]'.
  - Found Python 'print()' syntax. In Corvus, use 'log(...)'.

[*] Recommended Corvus Correction:
--------------------------------------------------------------------------------
mk func calculate(x) [
    log(x * 2)
]
--------------------------------------------------------------------------------
```

### 4. Python-to-Corvus Transpiler (`corvus ai translate`)
Translate Python code into valid Corvus source code:

```bash
corvus ai translate app.py
```

Given `app.py`:
```python
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

print("Fibonacci of 10:", fibonacci(10))
```

RavenAI generates:
```corvus
mk func fibonacci(n) [
    if (n <= 1) [
        givout n
    ]
    givout fibonacci(n - 1) + fibonacci(n - 2)
]

log("Fibonacci of 10:", fibonacci(10))
```

You can execute the translated code immediately using the Corvus interpreter or compiler:
```bash
corvus ai translate app.py > app.crv
corvus app.crv
```

### 5. Interactive Assistant REPL (`corvus ai chat`)
Start a persistent terminal session with RavenAI:

```bash
corvus ai chat
```

**Interactive Commands**:
- `code--ask <question>` — Ask syntax and architecture questions
- `code--summary <file.crv>` — Summarize a Corvus file
- `code--fix <code or file>` — Detect and fix syntax or Pythonisms
- `code--translate <file.py>` — Transpile Python code to Corvus
- `exit` or `quit` — Exit the assistant REPL

```text
================================================================================
  Corvus RavenAI Interactive Developer Terminal (v4.7)
  Type 'code--ask <query>', 'code--summary <file>', 'code--fix <code>',
  'code--translate <py_file>', or 'exit' to quit.
================================================================================

RavenAI> code--ask how to loop over a list
[RavenAI Knowledge Base]
Topic: Loops & Iterations
Usage in Corvus:
for item in [1, 2, 3] [
    log(item)
]

RavenAI> exit
Goodbye! Happy coding in Corvus!
```
