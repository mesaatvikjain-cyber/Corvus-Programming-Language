# Corvus v4.5 Hands-On Tutorial: Bytecode Virtual Machine, .crvc Compiler & Disassembler

Welcome to **Corvus Version 4.5**!

Corvus v4.5 introduces the **Corvus Bytecode Virtual Machine (CorvusVM)**, a compact binary executable format (`.crvc`), an AST-to-bytecode compiler, and an instruction disassembler.

Developers now have **three distinct execution strategies**:
1. **Interactive / AST Interpreter**: Instant startup, interactive REPL, and AST debugging with `--ai-fix`.
2. **Corvus Bytecode Virtual Machine (`CorvusVM`)**: Fast, compact `.crvc` binary distribution, portable bytecode execution, and inspection via `corvus dis`.
3. **C99 Native Compiler (`CorvusC_c`)**: Maximum bare-metal performance, compiling Corvus source directly into native binary executables with `-O3` passes.

---

## 🌟 What's New in v4.5?

1. **Compact Binary Bytecode Specification (`.crvc`)**:
   - Magic Header: `b"CRVC\x01\x00"` (Corvus Bytecode Format 1.0).
   - Fast binary serializer and deserializer with constant pool, identifiers table, and line tracking.
2. **High-Performance Stack Virtual Machine (`CorvusVM`)**:
   - Stack machine with activation call frames (`Frame`), local/global scope resolution, and native builtins dispatch.
   - First-class matrix multiplication (`@`) evaluation in `OpCode.MATMUL` for 2D matrices and NumPy/Torch arrays.
3. **Bytecode Compiler (`compiler_vm.py`)**:
   - Translates all Corvus language constructs: variables, expressions, loops (`while`, `for`), conditionals (`if`/`elsif`/`else`), functions, lambdas, pattern matching (`match`), and f-strings.
4. **Bytecode Disassembler (`corvus dis`)**:
   - Detailed disassembly showing instruction pointers, opcodes, constant values, variable names, and jump targets.
5. **Toolchain CLI Integration**:
   - `corvus compile <file.crv> [-o out.crvc]`
   - `corvus dis <file.crv | file.crvc>`
   - `corvus --vm <file.crv | file.crvc>`
   - Auto-executes `.crvc` files when passed directly: `corvus app.crvc`.

## 1. Writing Corvus Code for the VM

Create a source file, for example `app.crv`:

```corvus
// High-Performance Matrix Multiplication & Function Call
set A = [[1, 2], [3, 4]]
set B = [[5, 6], [7, 8]]
set C = A @ B

func compute_total(matrix, scale) [
    set total = 0
    for row in matrix [
        for val in row [
            total = total + (val * scale)
        ]
    ]
    givout total
]

set grand_total = compute_total(C, 2)
log(f"Matrix C: {C}")
log(f"Grand Total (scaled x2): {grand_total}")
```

---

## 2. Compiling to Binary Bytecode (`.crvc`)

Use the `corvus compile` command:

```bash
corvus compile app.crv -o app.crvc
```

Output:
```text
[Corvus Bytecode Compiler]: Successfully compiled 'app.crv' -> 'app.crvc' (842 bytes)
```

The resulting `app.crvc` file is a compact binary representation of your program containing the bytecode instructions, constants, and function definitions.

## 3. Disassembling Bytecode (`corvus dis`)

Inspect the generated bytecode with the built-in disassembler:

```bash
corvus dis app.crvc
```

## 4. Executing Bytecode with CorvusVM

You can run precompiled `.crvc` files directly with zero overhead:

```bash
corvus app.crvc
```

Or execute `.crv` source files directly on the Virtual Machine without emitting a file on disk:

```bash
corvus --vm app.crv
```

Output:
```text
Matrix C: [[19, 22], [43, 50]]
Grand Total (scaled x2): 268
```

## 5. Dual Engine Architecture Comparison

| Feature | AST Interpreter | Corvus Bytecode VM | C99 Native Compiler |
| :--- | :--- | :--- | :--- |
| **Command** | `corvus app.crv` | `corvus app.crvc` or `corvus --vm app.crv` | `corvusc app.crv -o app.exe --run` |
| **Execution Tier** | AST Tree Walking | Stack-Based Bytecode VM | Native Machine Code (x86_64) |
| **Startup Overhead** | Minimal (instant) | Ultra-fast (precompiled `.crvc`) | Requires C compilation step |
| **File Artifact** | `.crv` (Plain text) | `.crvc` (Compact binary bytecode) | `.exe` / ELF / Mach-O binary |
| **Inspection** | AST / Profile | `corvus dis <file>` | GCC / Clang / MinGW `-O3` |
| **Zero-Python Support**| Via Standalone `.exe` | Via Standalone `.exe` | Fully Standalone Binary |
