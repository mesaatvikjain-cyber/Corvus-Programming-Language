# Corvus v5.0 Hands-On Tutorial: Enterprise Developer Ecosystem

Welcome to **Corvus Version 5.0**!

Corvus v5.0 is the **Enterprise Ecosystem Milestone**. It expands Corvus with an automated developer toolchain: **RavenAI 2.0** (test generator, doc generator, static code review, reverse transpiler), **CPM 2.0** package manager, **Native Micro Web Framework** (`std_web`), an **Interactive CLI Tour** (`corvus tour`), a **Language Server Protocol Daemon** (`corvus lsp`), and **WebAssembly Compilation** (`--target wasm`).

---

## 🌟 1. RavenAI 2.0 Developer Suite

### Automated Unit Test Generator (`corvus ai testgen`)
Generate complete, runnable test assertions with standard calls and zero/boundary checks:
```bash
corvus ai testgen Examples-and-Tests/02_recursion_factorial.crv -o test_factorial.crv
corvus test_factorial.crv
```

### Automated Documentation Generator (`corvus ai doc`)
Inspect classes, fields, methods, and functions to create Markdown documentation:
```bash
corvus ai doc Examples-and-Tests/04_classes_and_oop.crv -o docs.md
```

### Static Code Review & Linting (`corvus ai review`)
Detect nested loops eligible for native `@` matrix acceleration, unused variables, and safety hazards:
```bash
corvus ai review Examples-and-Tests/17_matrix_matmul_suite.crv
```

### Reverse Transpiler (`corvus ai export`)
Export Corvus source code into clean Python or ISO C99:
```bash
corvus ai export Examples-and-Tests/02_recursion_factorial.crv --target py
corvus ai export Examples-and-Tests/02_recursion_factorial.crv --target c
```

## 📦 2. CPM 2.0 Package Manager

Manage project dependencies seamlessly:
```bash
# 1. Initialize a new project manifest
corvus pkg init my_project

# 2. Add an external package from Git
corvus pkg add https://github.com/user/corvus-game-engine

# 3. Install all dependencies from corvus.json
corvus pkg install

# 4. List all installed packages
corvus pkg list
```

## 🌐 3. Native Micro Web Framework (`web`)

Build REST APIs and web servers in pure Corvus:
```corvus
get web

set app = web.server()

app.route("/", mk func(req) [
    givout {"status": 200, "message": "Corvus Web API is running!"}
])

app.route("/api/calculate", mk func(req) [
    set a = req.params["a"] ?? 0
    set b = req.params["b"] ?? 0
    givout {"sum": a + b}
])

log("Listening on http://127.0.0.1:8080...")
app.listen(8080)
```

## 🎓 4. Interactive CLI Tour (`corvus tour`)

Launch an in-terminal interactive tutorial course:
```bash
corvus tour
```
Covers 8 guided lessons with real-time code evaluation and hints:
1. Hello World & `log()`
2. Variables & Type Inference (`set`, `const`)
3. Functions & Returns (`mk func`, `givout`)
4. Block Scoping `[ ... ]` vs `{ ... }`
5. Object-Oriented Classes (`cls`, `self.`)
6. Matrix Math (`@`)
7. Concurrency with Crows (`crow`)
8. Error Handling (`try ... error ... final`)

## 🔌 5. Language Server Protocol (`corvus lsp`)

Connect any modern editor (VS Code, Neovim, Sublime, Helix) to Corvus via standard JSON-RPC:
```bash
corvus lsp
```
* **Real-time Diagnostics**: Red error squiggles for syntax errors.
* **Hover Documentation**: Detailed syntax guides when hovering over keywords and functions.
* **Auto-completion**: Suggestions for language keywords, types, and standard libraries.

## ⚡ 6. WebAssembly Compilation (`--target wasm`)

Compile Corvus programs directly to WebAssembly Text format (`.wat`):
```bash
corvus compile app.crv --target wasm -o app.wat
```
Automatically outputs a companion `app.html` for running in any browser without Python!
