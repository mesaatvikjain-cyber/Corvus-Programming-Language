1. Introduction & The Story of Corvus

Welcome to the official master documentation and interactive tutorial hub for the Corvus Programming Language!

The Story Behind Corvus

"I got inspired to build my own programming language after watching a video about a programmer who created G# and C#, and a video by AstroSam. Since I already knew Python, I decided to take on the challenge and build my very own programming language from scratch!"
— Saatvik Jain (Creator of Corvus)

Corvus introduces a distinctive syntax using square brackets [ ... ] for code blocks and reserving curly braces { ... } for native lists. Over 6 major release iterations (v1.1 to v4.1), Corvus has evolved from an interpreted prototype into a multi-platform systems language featuring Three-Address Code (TAC) IR optimization, a self-hosted compiler, native C FFI, scope memory ref-counting, and a native assembly compiler generating 64-bit binaries for Windows, Linux, and macOS!

3. Syntax & Variables

In Corvus, statements are scoped inside square brackets [ ... ]. Variables are declared using var (mutable) or const (immutable).

# Mutable Variable Declaration
var score = 100
set score = score + 50

# Immutable Constant Declaration
const MAX_USERS = 500

# Native List Literals
var numbers = {10, 20, 30, 40}

# Tuple Literals & Dictionary Maps
var user = ("Saatvik", 2026)
var config = {"host": "localhost", "port": 8080}

4. Control Flow

Corvus provides rich control flow structures including conditional branches (if/elsif/else), loops (while, for), and panic-resilient error handling blocks (try/catch).

var val = 42

if (val > 50) [
    log("Value is greater than 50")
] elsif (val == 42) [
    log("Answer to life, the universe, and everything!")
] else [
    log("Value is smaller")
]

# While Loop
var i = 0
while (i < 5) [
    log("Iter: " + str(i))
    set i = i + 1
]

# Try / Catch Block
try [
    var res = 10 / 0
] catch [
    log("Caught arithmetic division error safely!")
]

5. Functions & Lambdas

Functions are defined using the func keyword and return values using givout.

func add(a, b) [
    givout a + b
]

func factorial(n) [
    if (n <= 1) [
        givout 1
    ]
    givout n * factorial(n - 1)
]

# First-class Lambda Function
var multiply = lambda (x, y) -> x * y
log(multiply(6, 7))  # Outputs: 42

6. Object-Oriented Programming (OOP)

Classes in Corvus are declared using class, featuring constructor methods (init) and instance reference binding (self).

class Vector2D [
    func init(x, y) [
        set self.x = x
        set self.y = y
    ]

    func magnitude() [
        givout math.sqrt(self.x * self.x + self.y * self.y)
    ]
]

var vec = Vector2D(3, 4)
log(vec.magnitude())  # Outputs: 5.0

7. Functional Programming Paradigms

Corvus includes modern functional paradigms such as the Pipeline Operator (|>) and Pattern Matching (match ... case).

# Functional Pipeline Operator (|>)
var result = 5 |> double |> add_ten
log(result)

# Pattern Matching (match / case)
var status_code = 200

match (status_code) [
    case 200: log("HTTP Success Status Code 200")
    case 404: log("HTTP Not Found Status Code 404")
    case 500: log("HTTP Internal Server Error 500")
    else: log("Unknown Status Code")
]

8. Memory Management & Garbage Collection

Corvus features deterministic heap memory management (mem module) with automatic scope ref-counting and zero-leak cleanup in NASM assembly compilation.

# Manual & Scope Heap Allocation
var ptr = mem.alloc(1024)   # Allocate 1024 bytes
mem.free(ptr)               # Free allocated memory

# Inspect Active Memory Statistics
var stats = mem.stats()
log("Allocated Bytes: " + str(stats.allocated))

9. "Murder of Crows" 🐦 Concurrency Engine

Corvus includes a built-in multi-threaded concurrency engine called "Murder of Crows" (crow module) with asynchronous task spawning (crow.fly), synchronization (crow.flock), and message channels (crow.channel).

# Spawn concurrent worker tasks
var t1 = crow.fly(heavy_computation_task, {1000})
var t2 = crow.fly(heavy_computation_task, {2000})

# Synchronize task execution (Flock)
var results = crow.flock({t1, t2})

# Thread-safe Channels
var ch = crow.channel()
ch.send("Data message from background task")
var msg = ch.receive()

10. Native C Foreign Function Interface (FFI)

The ffi module enables Corvus code to dynamically load external C shared libraries (.dll, .so, .dylib) and invoke native C functions directly.

# Load dynamic C library (e.g. user32.dll or libc)
var user32 = ffi.load("user32.dll")
var MessageBox = ffi.bind(user32, "MessageBoxA", "int", {"int", "str", "str", "int"})

# Invoke native C function directly
ffi.call(MessageBox, {0, "Hello from Native Corvus C FFI!", "Corvus FFI", 0})

12. Compiler Architecture & v4.1 Super Optimizer

The Corvus compiler driver lowers AST into linear Three-Address Code (TAC) Intermediate Representation (IR), passes it through the v4.1 Super High-Level Optimization Engine, and emits 64-bit NASM assembly binaries.

v4.1 Super Optimizer Passes

1. Constant Propagation Pass: Propagates constant variables across basic blocks.
2. Strength Reduction & Algebraic Simplification: x * 0 -> 0, x * 2^n -> x << n, x / 2^n -> x >> n.
3. Constant Branch Folding: Evaluates if (1) at compile time.
4. CFG Jump Threading: Collapses chained jumps.
5. Assembly Peephole Pass: Eliminates redundant store/load sequences in NASM output.

13. Self-Hosted Architecture

Corvus achieved self-hosting in Version 3.0. The entire compiler frontend and interpreter parser are written directly in native Corvus syntax inside Compiler_SelfHosted/CorvusCompiler.crv and CorvusInterpreter.crv.

Version 4.3 is Corvus's flagship ecosystem release: complete 100% compiler-interpreter feature parity, standalone C99 native transpiler with -O3 optimizations, first-class Machine Learning stacks, AST optimization engine, and an actionable Rust-style diagnostic engine.

Flagship v4.3 Capabilities

1. 100% Compiler-Interpreter Feature Parity: Run scripts dynamically in the interpreter or compile to standalone native C99/assembly executables with identical execution results.
2. Native Matrix Multiplication Operator (@): Fast 2D matrix multiplication for lists, NumPy, and PyTorch in both interpreted and compiled native modes.
3. High-Performance C99 Native Transpiler (-O3): Transpile Corvus directly to optimized C99 and compile with Clang or GCC.
4. AST Optimization Engine (--optimize): Compile-time constant folding, algebraic simplification (x * 0 → 0, x * 1 → x), and dead-branch pruning.
5. Modern Syntax: F-Strings & Inline Ternaries: Interpolated formatted strings f"Hello {name}, score: {val * 2}" and inline ternary expressions cond ? true_val : false_val.
6. High-Precision Benchmarking & AST Profiler: Built-in corvus bench and corvus profile CLI commands measuring nanosecond execution, ops/sec throughput, peak RAM, and AST breakdown.
7. Rust-Style Diagnostic Catalog (--explain <CODE>): Over 18 cataloged error codes with root-cause diagnostics and verified fixes.
8. 30+ Standard Library Modules: Spans cryptography, networking, system control, embedded SQLite, and math extensions.
